# FPS Similarity Island Workflow

This workflow evaluates Footprint Score (FPS) Similarity Island clustering in DOCK6 over multiple FPS cutoff values.

The FPS implementation uses Cartesian receptor interaction footprints, Euclidean comparison, and combined van der Waals/electrostatic (`vdw_es`) footprint scoring.

The default cutoff experiment is:

    0 1 3 5 7 10 15 20

The calculations use the same ligand population, receptor, grid, and scoring configuration so that changes in clustering behavior can be compared directly as a function of FPS cutoff.

## Scripts

`000.config.sh`

Defines FPS cutoffs, DOCK6 paths, ligand file, receptor file, grid prefix, SLURM partition, walltime, and workflow paths.

Run:

    bash 000.config.sh

`001.setup_FPS_runs.sh`

Validates the required files and generates one DOCK6 FPS input file for each cutoff.

Run:

    bash 001.setup_FPS_runs.sh

`002.make_task_list.sh`

Creates `FPS_tasks.tsv`, mapping each FPS cutoff to its corresponding DOCK6 calculation.

Run:

    bash 002.make_task_list.sh

`003.run_one_task.slurm`

Runs one FPS calculation from the task list. This script is called automatically by the chunk runner.

`004.run_FPS_chunks.slurm`

Runs the FPS calculations assigned to one compute node. Independent FPS calculations are executed concurrently.

`005.submit_FPS.sh`

Submits the FPS cutoff experiment to SLURM using the partition and walltime defined in `000.config.sh`.

Run:

    bash 005.submit_FPS.sh

`006.collect_FPS_results.py`

Checks completed calculations and extracts experimental clustering information from the DOCK6 output files.

It generates:

    FPS_status.csv
    FPS_analysis_summary.csv
    FPS_island_statistics.csv

The analysis summary contains quantities including FPS cutoff, total islands, largest and smallest islands, mean and median island size, singleton islands, FPS calculation counts, runtime, throughput, and memory usage.

The FPS `.dat` files generated by DOCK6 are not analyzed by this script.

Run after the calculations finish:

    python3 006.collect_FPS_results.py

`007.analyze_FPS_results.py`

Reads `FPS_analysis_summary.csv` and displays the cutoff experiment in comparative form.

Run:

    python3 007.analyze_FPS_results.py

## Workflow

Generate the input files:

    bash 001.setup_FPS_runs.sh

Generate the task list:

    bash 002.make_task_list.sh

Submit the calculations:

    bash 005.submit_FPS.sh

After the calculations finish, collect the experimental results:

    python3 006.collect_FPS_results.py

Inspect the cutoff comparison:

    python3 007.analyze_FPS_results.py

The main dataset for comparing FPS clustering behavior across cutoff values is:

    FPS_analysis_summary.csv
